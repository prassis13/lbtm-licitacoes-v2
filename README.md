# LBTM — Central de Licitações Públicas v2.0

Inteligência Estratégica em Editais baseada na Lei nº 14.133/2021.

## 🚀 Funcionalidades da Versão 2.0 (LBTM v2.0)

1. **Arquivo Único (Single Page Application)**: Construído com Tailwind CSS e processador PDF.js integrado, sem dependências complexas de backend.
2. **🔄 Nova Licitação (Limpar Tela)**: Reinicialização e limpeza de memória do navegador para alternar entre diferentes editais sem travamento.
3. **📲 Copiar para WhatsApp**: Geração automática de Relatório Executivo estruturado e visual pronto para envio direto via WhatsApp para o gestor/diretor.
4. **💰 Tabela Interativa de Preços & Trava Legal**: 
   - Cálculo dinâmico de teto de referência, preços unitários e totais.
   - Alerta inteligente de desconto > 50% (risco de inexequibilidade conforme Lei 14.133/2021).
   - Verificação de propostas acima do valor teto.
5. **🏢 Perfil LBTM & Campos Dinâmicos**: Customização flexível de exigências específicas do edital (dados bancários, CREA, certidões).
6. **📄 Proposta Comercial Oficial A4**: Gerador de proposta no formato oficial padrão A4, pronta para impressão ou exportação em PDF.

## 🛠️ Como Executar

Basta abrir o arquivo `index.html` em qualquer navegador moderno (Chrome, Edge, Firefox, Brave).
